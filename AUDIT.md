# Аудит лендинга «Перлина»

Дата: 10.10.2026 · Angular 22.2 (SSR + prerender) · Проверялся production-билд через SSR-сервер (`node dist/perlyna/server/server.mjs`).
Инструменты: Lighthouse 12 (мобильный — эмуляция Moto G Power + медленный 4G; десктоп — preset `desktop`), axe-core 4 (`@axe-core/playwright`), Playwright, curl.

## 3. Итоговые проверки

**Сборка.** `ng build` — 0 ошибок, 0 предупреждений, бюджеты соблюдены. Пререндер: `/`, `/polityka-konfidentsiinosti`.
Начальный JS+CSS — 389 КБ raw / **106 КБ gzip**. Ленивые чанки: Three.js (125 КБ gzip, только по условию), GSAP+ScrollTrigger, Lenis, форма, секции.

**SSR (curl).** HTML от сервера содержит весь текст всех 12 секций (страхи, услуги, прайс, технологии, врачи, кейсы, рассрочка, отзывы, FAQ, форма), `<html lang="uk">`, title, description, canonical, 10 OG-тегов, Twitter Card, гео-мета и JSON-LD. HTML главной — 35 КБ gzip. Ошибок гидратации (`NG05xx`) в консоли нет; event replay проверен: клик по CTA до гидратации (при искусственно замедленном JS) открывает модалку.

**SEO.** Title 60 символов с ключами («Стоматологія Київ без болю — імплантація, вініри | «Перлина»»), description 155 символов — оба укладываются в сниппет Google (изначально были 73 и 187 символов и обрезались — сокращены в ходе аудита). Один `h1` («Стоматологія в Києві без болю та страху»), 12 `h2`, `h3` внутри секций. Ключевые запросы в заголовках и текстах: «стоматологія Київ», «імплантація зубів у Києві», «вініри в Києві», «стоматолог без болю». У всех `<img>` есть `alt` (декоративные — пустой). `robots.txt`, `sitemap.xml`, `manifest.webmanifest`, OG-картинка 1200×630. Неизвестный адрес — HTTP 404 (`RenderMode.Server, status: 404`), страница 404 закрыта `noindex`.
JSON-LD (`@graph`): `WebSite`; `Dentist` + `MedicalClinic` (адрес, телефон, часы, `GeoCoordinates`, `AggregateRating` 4.9/418, 7 `Review`, `OfferCatalog` из 6 услуг с ценой «від»); `FAQPage` (8 вопросов). JSON валиден; только на главной.

**Доступность.** axe (WCAG 2.0/2.1/2.2 AA + best practices): **0 нарушений** на 1440 и 390 px, в модальном окне тоже. Клавиатура: первая клавиша Tab — «Перейти до вмісту»; видимый фокус (2 px, `#0b7a70`) на всех элементах; вкладки прайса (←/→/Home/End) и технологий (↑/↓) по паттерну WAI-ARIA Tabs; карусель — стрелки; FAQ и детали врачей — `aria-expanded`/`aria-controls`; модалка — нативный `<dialog>` (ловушка фокуса, Esc, возврат фокуса).

**Адаптив.** 360 / 768 / 1024 / 1440 px — горизонтального скролла нет (`scrollWidth − innerWidth = 0`), переполнений элементов нет, консоль чистая.

**Анимации.** Анимируются только `transform`, `opacity`, `filter` (исключение — раскрытие FAQ и деталей врачей через `grid-template-rows`). CLS = 0. `prefers-reduced-motion`: класс `motion` не ставится → весь контент виден сразу, 3D не загружается (статичный постер), нет автопрокрутки карусели, нет Lenis.

**Форма** (Playwright, сценарий целиком): ошибки для всех обязательных полей; маска `0671234567 → +380 (67) 123-45-67`, вставка `+380501112233 → +380 (50) 111-22-33`; прошедшая дата отклоняется; офлайн → `role="alert"`; состояние «Надсилаємо…» → успех «Дякуємо, Олена!» с датой; заявка в `localStorage`; Esc закрывает модалку, фокус возвращается.

**Код.** Нет `any`, `console.*`, неиспользуемых переменных/параметров (`tsc --noUnusedLocals --noUnusedParameters`); `strict` + `strictTemplates` + extended diagnostics как ошибки. Standalone-компоненты, signals, `input()/output()`, `@if/@for/@defer`, OnPush по умолчанию (Angular 22), `@Service()`, `inject()`, Signal Forms, `NgOptimizedImage`. Весь код с `window`/GSAP/Three.js/Lenis — в `afterNextRender`, обработчиках событий или под `isPlatformBrowser`.

## 5. Оставшиеся рекомендации

1. **Реальные данные.** Контакты, врачи, отзывы и фото — демонстрационные (Unsplash). Для продакшена: реальные фото кейсов «до/після» (сейчас состояние «до» — тонировка того же снимка), отзывы с подтверждённых источников, реквизиты лицензии МОЗ.
2. **Отправка заявок.** Форма фейковая (localStorage). Для бизнеса — подключить CRM / Telegram-бота через серверный роут (SSR-сервер уже есть) или сервис форм.
3. **Мобильный LCP** у предела (2,44–2,48 с в лабораторной симуляции; реальный LCP ≈ 130 мс локально). Запас можно получить, сократив стартовый JS (вынести анимационные директивы в отдельный чанк) и подавая HTML с CDN (TTFB ~450 мс в симуляции).
4. **Шрифты** — `optional`: на очень медленном первом визите заголовки отрисуются метрически подогнанным Arial. Если бренд важнее CLS — вернуть `swap` (потеря ~0,05 CLS на мобильном).
5. **Самообслуживаемые отзывы** в JSON-LD (Review на собственной странице) Google не показывает в выдаче как звёзды — для сниппетов нужны отзывы из Google Business Profile.
6. **Деплой.** Canonical, sitemap и OG указывают на `https://perlyna.clinic` — при демо-хостинге на GitHub Pages это правильно (без дублей в индексе), но домен нужно заменить на реальный.
7. **E2E-тесты.** Сценарии из аудита (Playwright) стоит оформить как тесты в репозитории и запускать в CI.
